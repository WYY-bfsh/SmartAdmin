## 0. 先记住这几条（违反就会白干）

1. **不要用** `smart-admin-api-java8-springboot2`、`smart-admin-web-typescript`、Jenkins、K8s。只用 Java17 + JS 后台 + uni-app H5。
2. 云安全组**只开** `TCP 22`、`TCP 8080`。**不要开** `3306` / `6379` / `1024`。做 VPN 时再加 `UDP 51820`（必须是 UDP，不是 TCP）。
3. 成功后**禁止** `docker compose down -v`。`-v` 会删掉 MySQL / Redis / 上传三个数据卷，库和图片全没。
4. 库密码**只写在** `deploy/.env`，本机和服务器各一份，不要写进 `docker-compose.yml`，不要提交到 Gitee。
5. 重新上传 zip **不要覆盖** 服务器上的 `deploy/.env`。覆盖后 compose 读到的密码和卷里真实密码对不上，后端起不来，且不可逆。
6. `url-prefix` 必须带端口：`http://175.27.131.7:8080/upload/`。少了 `:8080`，上传的图全部 404。
7. 四个容器起来**不等于部署成功**。还必须导入 `restore-project-modules.sql`，否则能登录但秒杀/媒体/客服/支付四组菜单全空。
8. 后端重启后必须再 `docker restart smartadmin-nginx`，否则接口全 502（Nginx 缓存了旧容器 IP）。
9. 格式化后**先不要**在 compose 里写 `10.66.66.1:3306:3306`。那是 WireGuard 网卡的地址，VPN 没装时绑定会失败，MySQL 起不来。先只留 `127.0.0.1:3306:3306`。
10. 中文文件名用 `scp` 容易乱码。`恢复数据库.sh` 先传到 `/tmp/restore-db.sh`，再在服务器改名。

## 3. 云控制台：重装系统后立刻做

腾讯云控制台，这台机器。

### 3.1 重装

- 系统选 **Ubuntu 22.04** 或 **24.04**（不要 Windows）
- 登录方式选 **密钥**（推荐）或先用密码再改密钥
- 默认用户一般是 `ubuntu`
- 建议配置：2 核 4G，磁盘 ≥ 40G。内存只有 2G 时先加 2G swap（见 17.12）

### 3.2 安全组（入站）

| 协议 | 端口 | 来源 | 要不要 |
| --- | --- | --- | --- |
| TCP | 22 | 建议只放你自己的公网 IP | 要 |
| TCP | 8080 | `0.0.0.0/0` | 要（客户访问站点 HTTP） |
| TCP | 443 | `0.0.0.0/0` | 要（无域名自签 HTTPS，见手册「HTTPS 自签」） |
| UDP | 51820 | `0.0.0.0/0` | 可选，只在做 WireGuard 时开 |
| TCP | 51820 | — | **不要**。WireGuard 不走 TCP，开了也没用 |
| TCP | 3306 / 6379 / 1024 | — | **不要**。库和 Redis 不对公网 |

改完点保存。安全组改错是外网打不开的第一原因。

### 3.3 网页终端写入 SSH 公钥（密钥登录打不通时必做）

控制台打开「登录 / 网页终端」，用 `ubuntu` 登录后执行：

```bash
mkdir -p ~/.ssh
chmod 700 ~/.ssh
nano ~/.ssh/authorized_keys
```

把下面这一整行贴进去（一行，不要换行、不要前后空格）：

```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIL2uyv5XkmTm9MoA/srJfNd8GwGWmaQSoPxPItwOw1Nv wyy-mall-server
```

保存退出（nano：`Ctrl+O` 回车，`Ctrl+X`），然后：

```bash
chmod 600 ~/.ssh/authorized_keys
whoami
```

必须打印 `ubuntu`。不是 `ubuntu` 就不要往下做，后面路径和 sudo 都会错。

### 3.4 sudo 免密（推荐，后面大量命令要 sudo）

```bash
sudo visudo
```

在文件末尾加一行：

```
ubuntu ALL=(ALL) NOPASSWD:ALL
```

保存退出。测一下：

```bash
sudo -n true && echo SUDO_OK
```

要看到 `SUDO_OK`。没有的话每次 sudo 都会停着等密码，脚本会卡住。

## 5. 安装 Docker（宿主机不装 JDK / Node / MySQL）

还在服务器 SSH 里执行。源用阿里云，国内直连 Docker 官方源会慢或失败。

```bash
sudo apt update
sudo apt install -y ca-certificates curl unzip

sudo curl -fsSL https://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://mirrors.aliyun.com/docker-ce/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
sudo usermod -aG docker ubuntu
```

**必须重新断开 SSH 再登录一次**（`usermod` 加组当前会话不生效）：

再测：

```bash

docker run --rm hello-world
```

## 6. Docker 镜像加速（不配，后面必卡）

国内直连 `docker.io` 拉 `node` / `mysql` / `redis` / `nginx` / `maven` 会超时。本项目已经踩过两次。

```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json >/dev/null <<'JSON'
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://docker.m.daocloud.io"
  ],
  "log-driver": "json-file",
  "log-opts": { "max-size": "20m", "max-file": "3" }
}
JSON
sudo systemctl restart docker
docker info | grep -A 5 "Registry Mirrors"
```

期望能看到上面两个镜像地址。

- `mirror.ccs.tencentyun.com` **只在腾讯云内网可用**。这台机器是腾讯云，留着。换到阿里云/华为云就把这一行删掉，只留 DaoCloud。
- `log-opts` 防止 `smartadmin-api` 日志几个月把磁盘写满。

预拉基础镜像（第一次 `up --build` 之前做，失败立刻知道）：

```bash
for i in mysql:8.0 redis:7-alpine nginx:alpine node:20-alpine maven:3.9-eclipse-temurin-17 eclipse-temurin:17-jre-alpine; do
  echo "===== $i ====="
  docker pull "$i" || echo "FAIL $i"
done
```

六条都要成功。哪条 `FAIL` 就不要往下走，先查镜像加速是否生效。  
配好之后，构建命令直接写 `node:20-alpine`，不必再写 `docker.m.daocloud.io/library/` 前缀。

## 9. 写库密码，并改掉 VPN 端口（格式化后必改）

### 9.1 `.env`

```bash
printf 'MYSQL_ROOT_PASSWORD=smart_admin_v3\n' > /data/smartadmin/deploy/.env
chmod 600 /data/smartadmin/deploy/.env
cat /data/smartadmin/deploy/.env
```

必须只有一行：`MYSQL_ROOT_PASSWORD=smart_admin_v3`。  
本机 `D:\Personal\project\smartadmin\deploy\.env` 也必须是同一个值。

### 9.2 去掉 WireGuard 地址绑定

打开 `/data/smartadmin/deploy/docker-compose.yml`，找到 `mysql` 的 `ports`。  
**格式化后机器上没有 `10.66.66.1` 这块网卡**，如果还写着：

```yaml
    ports:
      - "127.0.0.1:3306:3306"
      - "10.66.66.1:3306:3306"
```

MySQL 容器会起不来。改成只留本机回环：

```yaml
    ports:
      - "127.0.0.1:3306:3306"
```

其余部分不要改。尤其这几处必须在：

- 文件第一行：`name: smartadmin`
- MySQL / 后端密码都是 `${MYSQL_ROOT_PASSWORD:?set MYSQL_ROOT_PASSWORD in deploy/.env}`
- 后端 JDBC 带 `allowPublicKeyRetrieval=true`（MySQL 8 必需，少了 api 起不来）
- Nginx 的 html **不要**加 `:ro`
- 上传卷挂的是 `upload-data:/upload:ro`，不是挂到 `/usr/share/nginx/html/upload`

完整可用的 `docker-compose.yml` 以本机仓库这份为准。改完后：

```bash
cd /data/smartadmin/deploy
docker compose config >/dev/null && echo COMPOSE_OK
```

**`COMPOSE_OK` 是硬门槛**。报 `set MYSQL_ROOT_PASSWORD in deploy/.env` 就是 `.env` 没写上或文件名错了，先修再往下。

顺手给恢复脚本去 Windows 换行（本机编辑过的 sh 经常带 CRLF，第一次执行会失败）：

```bash
sed -i 's/\r$//' /data/smartadmin/deploy/恢复数据库.sh
chmod +x /data/smartadmin/deploy/恢复数据库.sh
```

## 11. 构建 Web 后台和商城 H5

必须在 `docker compose up` **之前**做。Nginx 挂的是编好的 `dist`，没编过容器能起、页面是 403/404。

```bash
cd /data/smartadmin

docker run --rm -v /data/smartadmin/smart-admin-web-javascript:/app -w /app \
  node:20-alpine sh -c \
  "npm config set registry https://registry.npmmirror.com && npm install && npm run build:prod"

test -f /data/smartadmin/smart-admin-web-javascript/dist/index.html && echo WEB_OK
```

期望最后一行 `WEB_OK`。`dist/index.html` 大约 3KB。vite 构建大约 1 分钟。

```bash
docker run --rm -v /data/smartadmin/smart-app:/app -w /app \
  node:20-alpine sh -c \
  "npm config set registry https://registry.npmmirror.com && npm install && npm run build:h5"

test -f /data/smartadmin/smart-app/dist/build/h5/index.html && echo H5_OK
ls /data/smartadmin/smart-app/dist/build/h5
```

期望 `H5_OK`。`index.html` 大约几百字节到 1KB。产物里的 JS/CSS 路径应是 `/app/assets/...`。

H5 在 alpine 上失败：把镜像换成 `node:18-alpine` 再跑同一条命令。  
构建时出现静态图路径的运行时解析警告，**可以忽略**，只要最后有 `index.html`。

给 H5 静态目录读权限（Nginx 容器用户读不到会 403）：

```bash
chmod -R a+rX /data/smartadmin/smart-admin-web-javascript/dist
chmod -R a+rX /data/smartadmin/smart-app/dist/build/h5
```

`manifest.json` 里 `h5.router.base` 必须是 `/app/`，不要改成 `/`，除非同时改 Nginx。

## 12. 启动四个容器

```bash
cd /data/smartadmin/deploy
docker compose config >/dev/null && echo COMPOSE_OK
```

## 16. 可选：WireGuard VPN 连库

不是上线必需。SSH 隧道够用就跳过本章。  
要做的话，**先把站点验收做完**，再装 VPN，避免两件事一起排错。

### 16.1 云安全组

加一条：**协议 `UDP`，端口 `51820`，来源全部 IPv4，允许。**  
只开 TCP 51820 = 没开。客户端会显示已激活，但「接收」一直是 0B。

### 16.2 服务器安装（格式化后重新生成密钥，不要复用旧的）

```bash
sudo apt-get update
sudo apt-get install -y wireguard wireguard-tools
sudo mkdir -p /etc/wireguard
umask 077
wg genkey | sudo tee /etc/wireguard/server.key | wg pubkey | sudo tee /etc/wireguard/server.pub
```

本机也要一对新密钥（PowerShell 没有 `wg` 时，可以在服务器再生成一对当客户端）：

```bash
wg genkey | tee /tmp/client.key | wg pubkey > /tmp/client.pub
echo CLIENT_PRIV=$(cat /tmp/client.key)
echo CLIENT_PUB=$(cat /tmp/client.pub)
echo SERVER_PUB=$(sudo cat /etc/wireguard/server.pub)
```

把三个值记下来。然后写服务端配置：

```bash
# 把下面 YOUR_CLIENT_PUB 换成上一步的 CLIENT_PUB
sudo tee /etc/wireguard/wg0.conf >/dev/null <<EOF
[Interface]
Address = 10.66.66.1/24
ListenPort = 51820
PrivateKey = $(sudo cat /etc/wireguard/server.key)

[Peer]
PublicKey = YOUR_CLIENT_PUB
AllowedIPs = 10.66.66.2/32
EOF

sudo chmod 600 /etc/wireguard/wg0.conf /etc/wireguard/server.key
echo 'net.ipv4.ip_forward=1' | sudo tee /etc/sysctl.d/99-wireguard.conf
sudo sysctl -w net.ipv4.ip_forward=1
sudo systemctl enable --now wg-quick@wg0
sudo wg show
ip addr show wg0
```

期望：有 `wg0`，地址 `10.66.66.1`。

### 16.3 把 MySQL 绑到 VPN 网卡

确认 `wg0` 已经存在之后，把 compose 的 mysql ports 改成：

```yaml
    ports:
      - "127.0.0.1:3306:3306"
      - "10.66.66.1:3306:3306"
```

然后：

```bash
cd /data/smartadmin/deploy
docker compose -p smartadmin up -d mysql
ss -lntn | grep 3306
```

期望同时看到 `127.0.0.1:3306` 和 `10.66.66.1:3306`。站点验证码必须仍是 200。

### 16.4 Windows 客户端

1. 安装包在 `D:\Personal\WireGuard\`（没有就去官网下 WireGuard for Windows）
2. 新建空隧道，内容：

```
[Interface]
PrivateKey = <CLIENT_PRIV>
Address = 10.66.66.2/32
DNS = 1.1.1.1

[Peer]
PublicKey = <SERVER_PUB>
Endpoint = 175.27.131.7:51820
AllowedIPs = 10.66.66.0/24
PersistentKeepalive = 25
```

3. 激活。等几秒，**接收必须 > 0B**。发送有、接收 0 = 安全组还是 TCP，或 51820 没开。
4. 断开再激活一次再看。

Navicat（走 VPN 时**不要**开 SSH 隧道）：

| 项 | 填 |
| --- | --- |
| 主机 | `10.66.66.1`（服务器 VPN 地址，**不是** `10.66.66.2`，也不是 `10.66.66.0`） |
| 端口 | `3306` |
| 用户 | `root` |
| 密码 | `smart_admin_v3` |

`10.66.66.0` 是网段，不是主机。`10.66.66.2` 是你自己的电脑。

卸载服务器 VPN（以后不想用了）：

```bash
sudo systemctl disable --now wg-quick@wg0
sudo apt-get remove -y wireguard wireguard-tools
sudo rm -rf /etc/wireguard
```

同时把 compose 里 `10.66.66.1:3306:3306` 删掉，只留 `127.0.0.1:3306:3306`，再 `docker compose -p smartadmin up -d mysql`。

## 18. 本轮全部踩坑（格式化后按这个排错）

### 18.1 SSH `Permission denied (publickey)`

网页终端把公钥写入 `/home/ubuntu/.ssh/authorized_keys`。用户必须是 `ubuntu`。

### 18.2 拉镜像超时（`node` / `mysql` / `redis` / `nginx`）

没配 `/etc/docker/daemon.json` 镜像加速。回到第 6 章。  
应急：`docker pull docker.m.daocloud.io/library/node:20-alpine && docker tag docker.m.daocloud.io/library/node:20-alpine node:20-alpine`

### 18.3 Maven `dependency:go-offline` EOF

不是内存不够（2.9G available 也会 EOF）。Dockerfile 必须 `COPY settings.xml /root/.m2/settings.xml`，内容是阿里云 `https://maven.aliyun.com/repository/public`。仓库里已经有这份文件。

### 18.4 Nginx 起不来：read-only file system / 挂 upload 失败

html 目录不要 `:ro`。上传卷挂 `/upload`，不要挂进只读的 `/usr/share/nginx/html/upload`。以仓库当前 `docker-compose.yml` 为准。

### 18.5 容器名冲突

上次半成品容器还在：

```bash
docker ps -a | grep smartadmin
# 确认没有业务数据后再：
docker compose -p smartadmin down
```

不要加 `-v`，除非你确定要清空库。

### 18.6 `恢复数据库.sh` 执行立刻失败或 `\r` 报错

Windows CRLF。`sed -i 's/\r$//' /data/smartadmin/deploy/恢复数据库.sh` 后再跑。

### 18.7 能登录，但没有秒杀/媒体/客服/支付

漏了第 13 章。表数不是 65、菜单不是 179。补导 `restore-project-modules.sql`，再 `FLUSHDB` + 重启 api 和 nginx。

### 18.8 后台报「系统似乎出现了点小问题」，日志 `Unknown column 'commission_rate_l2'` 或 `commission_level`

表在、列不在。执行第 13 章末尾两条 `ALTER TABLE`。Java 里 `CREATE TABLE IF NOT EXISTS` **不会**给已存在的表加列。

### 18.9 验证码接口 500 / api 起不来：`Public Key Retrieval is not allowed`

JDBC URL 必须带 `allowPublicKeyRetrieval=true`。改 compose 后：

```bash
cd /data/smartadmin/deploy
docker compose -p smartadmin up -d --force-recreate sa-admin
docker restart smartadmin-nginx
```

### 18.10 改了 `.env` 密码但后端连不上

MySQL **只在第一次初始化空卷时**读取 `MYSQL_ROOT_PASSWORD`。之后只改 `.env` 不会改库里的密码。必须：

```bash
# OLD 是库里现在的密码，NEW 是你想改成的
docker exec -i smartadmin-mysql mysql -uroot -p"$OLD" -e "
ALTER USER 'root'@'%' IDENTIFIED BY '${NEW}';
ALTER USER 'root'@'localhost' IDENTIFIED BY '${NEW}';
FLUSH PRIVILEGES;"
printf 'MYSQL_ROOT_PASSWORD=%s\n' "$NEW" > /data/smartadmin/deploy/.env
# 本机 .env 同步改
docker compose -p smartadmin up -d --force-recreate sa-admin mysql
docker restart smartadmin-nginx
```

### 18.11 Navicat `10061`

3306 不对公网开放。用第 15 章 SSH 隧道，主机填 `127.0.0.1`，不要填公网 IP。  
用户名是 `root`，不是库名 `smart_admin_v3`。

### 18.12 WireGuard 已激活但接收 0B

安全组开成了 TCP 51820。改成 **UDP** 51820。然后客户端断开再激活。

### 18.13 WireGuard 通了，Navicat 仍连不上

主机必须是 `10.66.66.1`，端口 `3306`。  
并且 compose 已经把 MySQL 绑到 `10.66.66.1:3306`（第 16.3 章）。只装 VPN、没改 compose，连的是一块没有 MySQL 的网卡。

### 18.14 后端重启后全部 502

Nginx 启动时把 `sa-admin` 解析成 IP 并缓存。`docker restart smartadmin-nginx`。日常更新命令已经绑定了这一步。

### 18.15 上传图片 404

`url-prefix` 少了 `:8080`，或重新打包把本机错误值覆盖到了服务器。搜 `175.27.131.7`，改完重新 `--build sa-admin`。

## 20. 关键文件该长什么样（对照用）

### 20.1 `deploy/.env`

```
MYSQL_ROOT_PASSWORD=smart_admin_v3
```

### 20.2 `deploy/docker-compose.yml` 要点

- 第一行 `name: smartadmin`
- mysql 镜像 `mysql:8.0`，库名 `smart_admin_v3`，密码读 `.env`
- mysql 端口格式化后只留 `127.0.0.1:3306:3306`
- redis 镜像 `redis:7-alpine`，不对外暴露端口
- sa-admin 的 JDBC：

```
jdbc:mysql://mysql:3306/smart_admin_v3?autoReconnect=true&useServerPreparedStmts=false&rewriteBatchedStatements=true&characterEncoding=UTF-8&useSSL=false&allowPublicKeyRetrieval=true&allowMultiQueries=true&serverTimezone=Asia/Shanghai
```

- nginx 端口 `8080:80`
- nginx 卷：

```
./nginx/conf.d                     → /etc/nginx/conf.d:ro
../smart-admin-web-javascript/dist → /usr/share/nginx/html          （不要 :ro）
../smart-app/dist/build/h5         → /usr/share/nginx/html/app:ro
upload-data                        → /upload:ro
```

- 三个命名卷：`mysql-data`、`redis-data`、`upload-data`

### 20.3 Nginx `location`

- `/` → 后台 `index.html`（history 路由）
- `/app/` → H5，回退 `/app/index.html`
- `/upload/` → `alias /upload/;`
